## Projects

**[Study Group Matcher](https://github.com/Aakash553-stack/aakashmunawar-site/tree/master/projects/study-group-matcher)**
· [Live demo](https://study.aakashmunawar.com) (one-click "Try the demo")
Full-stack web app that matches Rutgers students into study groups by shared courses and
overlapping weekly free time. The matching algorithm is written from scratch and checked
against a brute-force model; 41 JUnit tests pass.
`Java` `Spring Boot` `Spring Security (JWT)` `PostgreSQL` `JPA` `JUnit`

**[Chicago Crime Explorer](https://github.com/Aakash553-stack/aakashmunawar-site/tree/master/projects/crime-data-explorer)**
· [Live dashboard](https://crime.aakashmunawar.com)
Interactive dashboard over 478,089 real Chicago Police Department incident reports, built
on a normalized SQL schema. Six filterable analyses reuse the original SQL queries.
`Python` `FastAPI` `SQLite` `SQL` `Chart.js`

**[Schedule Builder](https://github.com/Aakash553-stack/aakashmunawar-site/tree/master/projects/schedule-builder)**
Finds every conflict-free class schedule from real Rutgers course data using backtracking,
then ranks them by preference. Up to 5.9× faster than brute force on a 5-course search.
`Python` `Algorithms`

**[Campus Route Finder](https://github.com/Aakash553-stack/aakashmunawar-site/tree/master/projects/campus-route-finder)**
Shortest walking routes across Rutgers–New Brunswick using Dijkstra's algorithm with a
hand-built priority queue, over real OpenStreetMap coordinates.
`Python` `Graph algorithms`
